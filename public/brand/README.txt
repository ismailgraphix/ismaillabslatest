ISMAIL LABS LOGO KIT

Colours
  Ink     #0F0F0F
  Accent  #4353FF
  White   #FFFFFF
Wordmark typeface: Space Grotesk (Bold + Regular), converted to outlines,
so the SVGs render the same everywhere without the font installed.

Logo (mark + "ismail labs")
  logo.svg / logo.png                    light backgrounds
  logo-on-dark.svg / logo-on-dark.png    dark backgrounds

Mark only
  mark.svg / mark.png                    light backgrounds
  mark-on-dark.svg / mark-on-dark.png    dark backgrounds
  app-icon-rounded.svg / .png            social avatars, app icon

Favicon set
  favicon.ico          16, 32 and 48 px in one file
  favicon.svg          modern browsers
  favicon-16/32/48.png
  apple-touch-icon.png 180 px (iOS home screen)
  icon-192.png, icon-512.png   web app manifest / Android

Social share
  social-share.png     1200 x 630, for the og:image tag

HTML head
  <link rel="icon" href="/favicon.ico" sizes="48x48">
  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <link rel="apple-touch-icon" href="/apple-touch-icon.png">
  <meta property="og:image" content="https://www.ismaillabs.com/social-share.png">

Keep clear space around the logo equal to the width of one bar, and do not
recolour, stretch or add effects to the mark.
